# Insta UI Lab

Educational Instagram-inspired login UI for learning Flask,
localhost development, redirects, and development tunnels.

## Important

This project is NOT affiliated with Instagram.

It is intentionally designed so that the password field is
never submitted to the Flask server.

Do not use this project for phishing, credential collection,
impersonation, or unauthorized access.

## Requirements

- Linux
- Python 3.9+
- pip
- Optional: ngrok

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Insta-UI-Lab.git
cd Insta-UI-Lab
